# mrwhyxxk.github.io

这是一个基于 GitHub Pages 的个人博客，使用 Jekyll 和 Minima 主题。

## 站点地址

https://mrwhyxxk.github.io/

## 本地预览

```bash
git clone https://github.com/mrwhyxxk/mrwhyxxk.github.io.git
cd mrwhyxxk.github.io
bundle install
bundle exec jekyll serve
```

欢迎来到我的博客。这里会记录技术学习、编程实践、生活感悟以及一些有趣的项目。
